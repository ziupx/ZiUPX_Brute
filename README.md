# ZiUPX Smart Brute 🕵️‍♂️

Умный брутфорсер директорий и файлов, который решает главную проблему классических сканеров — ложные срабатывания.

## 🧠 В чем фишка?

Обычные инструменты (вроде dirb или gobuster) просто перебирают слова из словаря. Если сайт настроен так, что на любой несуществующий адрес он отдает код 200 OK (страницу с текстом "Упс, ничего не найдено"), классические сканеры выдают тысячи ложных результатов.

ZiUPX Smart Brute делает иначе:

1. Перед началом сканирования он заходит на заведомо несуществующую страницу (например, `/super-fake-page-123`) и замеряет её размер.
2. Во время брутфорса он отсеивает все страницы, чей размер совпадает с размером "фейковой" страницы.
3. Если же найден файл с другим размером (например, robots.txt), скрипт не просто покажет его, а попытается прочитать содержимое (если это текст) и выведет первые строки.

## 🚀 Возможности

- **Умная калибровка:** Автоматическое определение размера страницы-ошибки.
- **Многопоточность:** Быстрый перебор благодаря `concurrent.futures`.
- **Анализ контента:** Чтение первых строк найденных текстовых файлов (HTML, JSON, TXT).
- **Цветной вывод:** Наглядное отображение кодов ответа (200, 301, 403).
- **Экспорт отчета:** Сохранение всех найденных путей в текстовый файл.
